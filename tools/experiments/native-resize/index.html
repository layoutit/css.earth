CSS orientation:

This indicator sits outside the resize box. The same two CSS numbers can feed a camera transform without moving the scene into the box.

drag → inline width / height → CSS view timelines → yaw / pitch

The timelines measure the box in a fixed 300px scrollport. The box begins 600px before the scrollport. At scroll offset zero, progress = 900 / (300 + size), so CSS recovers size = 900 / progress − 300. No scrolling or script runs to copy the values.
