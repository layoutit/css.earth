# Native Celestia CMS exporter

The mesh is generated by **the original Celestia `SphereMesh` and Perlin noise
code**, pinned to `e9997cc011a57fdcc507f4ef5352bfd03cb17a6b`. Files under
`celengine/`, `celmath/` and `celcompat/` are unchanged upstream bytes. Their
hashes, original URLs and credits are recorded in `upstream.json`.

`export.cpp` supplies the fields from `asteroid.cms` or `roughsphere.cms` to
`SphereMesh`, then captures `convertToMesh()` vertex bytes and triangle strips.
The `shim/celmodel/mesh.h` adapter only stores that output. It implements no
geometry or noise. `meshmanager.cpp` and `model.cpp` are pinned references for
Celestia's loading and normalization behavior; they are not linked.

Modern Celestia seeds its noise from a random device. A CMS file consequently
does not identify one immutable set of vertices. This export calls Celestia's
public RNG API with **seed 20260909** before its first noise-table initialization.
Both meshes use that same seed, as a shared catalog resource would. Two separate
native processes produced identical output for each mesh. The native output is
checked in so normal package rebuilds do not depend on compiler or standard
library differences in random-distribution implementations.

## Build and export

Download and verify the Eigen 3.4.0 archive named and hashed in `upstream.json`.
Eigen is used only by the offline C++ exporter, under its upstream licenses.
Extract it under `output/celestia-comets/native/eigen-3.4.0`, then from repo root:

```sh
clang++ -std=c++20 -O2 -ffp-contract=off \
  -Ioutput/celestia-comets/native/eigen-3.4.0 \
  -Itools/objects/celestia-comets/native/shim \
  -Itools/objects/celestia-comets/native \
  tools/objects/celestia-comets/native/celengine/spheremesh.cpp \
  tools/objects/celestia-comets/native/celmath/randutils.cpp \
  tools/objects/celestia-comets/native/export.cpp \
  -o output/celestia-comets/native/export
node tools/objects/celestia-comets/export-meshes.mjs
```

The `.native.json` outputs retain all 5,050 native vertices and the original
triangle-strip indices. The OBJ conversion:

- Follows `Model::normalize`: bounding-box center, maximum full extent of two.
- Applies `[x, -z, y]`, a proper rotation from Celestia Y-up to cssEarth Z-up.
- Joins duplicated longitude seams and pole vertices, with measured differences
  below 2e-7 normalized units, and omits 200 degenerate polar triangles.
- Preserves the remaining **4,802 vertices and 9,600 triangles**. No surface
  deformation or replacement geometry is introduced.

Each package uniformly scales this normalized mesh by the catalog radius in
metres. Its camera reference uses the mesh's volume-equivalent radius; the
catalog diameter remains the maximum full extent. The common meshoptimizer
preparer reduces it to 800 display triangles. The grid is prepared through the
normal missing-imagery path, and Shadows defaults off.
