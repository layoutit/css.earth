NEOWISE Derived Diameters and Albedos of Solar System Small Bodies Catalog Definitions V2

Overview

This data set is version 2 of a compilation of published diameters, optical albedos, near-infrared albedos, and beaming parameters for Solar System small bodies detected by NEOWISE during the WISE 4-Band Cryo, 3-Band Cryo, Post-cryo and NEOWISE-Reactivation Year 1, Year 2, and Year 3 survey phases. It contains data for near-Earth asteroids, Main Belt asteroids, active Main Belt objects, Hildas, Jupiter Trojans, and Centaurs. The methodology for physical property determination is described in the referenced articles.

These data were originally published in the referenced articles. Please cite the appropriate original reference when using these data.

NEOWISE diameters and albedos derived from the WISE 4-Band Cryo, 3-Band Cryo, Post-cryo and NEOWISE Reactivation Year 1, Year 2, and Year 3 measurements are also available in the NASA Planetary Data System Small Bodies Node Asteroid/Dust Archive. Note that version 2 supersedes the first delivery to PDS.

ASTEROID_NUMBER int Asteroid number, if any.
PROV_DESIG char Provisional designation of object as assigned by the MPC, if any.
COMET_DESIG char Comet designation, if any.
MPC_PACKED_NAME char Number or provisional designation of object in MPC-packed format. Included for locating objects in published tables.
ABSOLUTE_MAG float MAGNITUDES Absolute H_V magnitude used as input to fitting routine.
SLOPE_PARAM float G slope param from H-G system used for calculating photometric phase effects.
MEAN_JD float DAY Mean Julian Date of observations used for fitting.
N_W1 int Number of W1 band measurements used for thermal fitting.
N_W2 int Number of W2 band measurements used for thermal fitting
N_W3 int Number of W3 band measurements used for thermal fitting
N_W4 int Number of W4 band measurements used for thermal fitting
FIT_CODE char Four character code indicating parameters allowed to vary in thermal fit:
D=diameter
V=Visible geometric albedo
B=NEATM beaming parameter
I=Infrared geometric albedo
"-"=parameter held fixed for fit.
DIAMETER float KILOMETER Best-fit effective spherical diameter, or assumed value if not fitted.
DIAMETER_ERR float KILOMETER Error on diameter.
V_ALBEDO float Best-fit visible geometric albedo or assumed value if not fitted.
V_ALBEDO_ERR float Error on visible albedo.
IR_ALBEDO float Best-fit infrared geometric albedo or assumed value if not fitted.
IR_ALBEDO_ERR float Error on infrared albedo.
BEAMING_PARAM float Best-fit NEATM thermal beaming parameter, or assumed value if not fitted.
BEAMING_PARAM_ERR float Error on beaming parameter.
STACKED_FLAG char Flag = S if fit is based on images co-added on the object's predicted position.
PDS_REF_CODE char PDS-formatted reference to the original publication of fitted parameters.
NOTES char Notes.
ADS_REF_CODE char ADS-formatted reference to the original publication of fitted parameters.
TYPE char Asteroid category type. Possible values are: ambos, centaurs, hildas, jupiter_trojans, mainbelt, mainbelt or mars crossers, neos
