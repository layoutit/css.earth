# Volume core ownership

- Keep deterministic numerical methods and validated, platform-neutral contracts here. No Node, DOM, React, HTTP, native image codecs, renderer imports or filesystem paths.
- No object-specific branches, source catalogues, research recipes or cache orchestration. Inputs carry the coordinate frames, units, source identity and scientific interpretation.
- Preserve arithmetic order, finite support, spectral semantics, missing-data handling and historical compatibility. A relocation must not change accepted pixels or relax validators.
- Material color does not define density. Keep component-bound 3D material distinct from historical image-ray samplers; never introduce an XY fallback into the finite-emission compiler.
- Export explicit subpaths. Every authored source file stays at or below 600 physical lines. Keep pure tests beside their owners when the migration moves them.
- Validate boundary values at runtime; assertions on TypeScript types are not validation.
- Typecheck with ECMAScript libraries only and run affected numerical/material/registration tests. No processing of native observations is needed to check a pure relocation.
