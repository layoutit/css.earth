## What “covered” means

- **Present** means the merged registry contains a standalone satellite package, not that deployment or all release gates were checked today.
- **Imagery lens** means a mapped observation view exists; it can be partial, coarse, monochrome, enhanced color, infrared or radar. It does not imply a complete photographic globe.
- **Shape without mapped imagery** includes released meshes, measured axes and explicit approximations; the body review distinguishes them.
- **Reviewed** means a bounded, body-specific source search produced a supported disposition, with unresolved access or scientific limits recorded.
- **Qualified** requires exact source/runtime closure, tests, build and real Chrome DPR 1/2 evidence at the implementation commit. No blanket qualification is assigned here.

Track implementation separately: **Not started → Source intake → Implementing → PR → Present → Qualified**, or **Blocked: concrete missing evidence**. The final column is editable ownership/task space. The completed source survey does not mark implementation started.
