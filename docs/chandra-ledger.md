## Receipts

An observation counts as reproduced only when a receipt beside its program parses, states the `cssearth-chandra-reproduction@1` schema, and names that program, that obsid, that detector and mode, and the level-2 product the program pins, with the size and digest of the archive file it compared. A receipt that says anything else is reported here and proves nothing.

None: every receipt beside a pinned program was accepted.
