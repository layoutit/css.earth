# Kepler-249 credits

Radius, mass and temperature: Radius 0.482 +/- 0.018 solar radii from Rowe et al. 2014, the stellar radius of the default parameter set of Kepler-249 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014ApJ...784...45R/abstract); Mass 0.510238 +/- 0.020399 solar masses from TICv8, the stellar mass of Kepler-249 c's parameter set from TICv8 (the default leaves it empty) in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2019AJ....158..138S/abstract); temperature from Rowe et al. 2014, the stellar temperature of the default parameter set of Kepler-249 b in the NASA Exoplanet Archive.

Colour: a Planck spectrum at the temperature of Rowe et al. 2014, the stellar temperature of the default parameter set of Kepler-249 b in the NASA Exoplanet Archive, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2078807228323035008: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
