# Kepler-42 credits

Radius, mass and temperature: Radius 0.17 +/- 0.04 solar radii from Muirhead et al. 2012, the stellar radius of the default parameter set of Kepler-42 c in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2012arXiv1201.2189M/abstract); Mass 0.13 +/- 0.05 solar masses from Muirhead et al. 2012, the stellar mass of the default parameter set of Kepler-42 c in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2012arXiv1201.2189M/abstract); temperature from Muirhead et al. 2012, the stellar temperature of the default parameter set of Kepler-42 c in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 2126556132093765888, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.

Placement: Gaia DR3 source 2126556132093765888: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
