# WASP-91 credits

Radius, mass and temperature: Radius 0.86 +/- 0.03 solar radii from Anderson et al. 2017, the stellar radius of the default parameter set of WASP-91 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2017A&A...604A.110A/abstract); Mass 0.84 +/- 0.07 solar masses from Anderson et al. 2017, the stellar mass of the default parameter set of WASP-91 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2017A&A...604A.110A/abstract); temperature from Anderson et al. 2017, the stellar temperature of the default parameter set of WASP-91 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 6386751579018596864, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 6386751579018596864: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
