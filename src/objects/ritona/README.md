# Ritona

Ritona is a trans-Neptunian object in the Kuiper belt.

## Identity

Ritona is 145452 Ritona, provisional designation 2005 RN43. The JPL Small-Body Database classes its orbit as trans-Neptunian.

## Sources

Source selections, recorded trials and open questions are in the [investigation ledger](investigations.json).

Illustrative sphere at the 679 (+55/-73) km diameter measured from thermal emission. No shape model is published. Vilenius et al. (2012), Astronomy & Astrophysics 541, A94; Herschel PACS and Spitzer MIPS thermal radiometry.

The orbit comes from JPL Horizons osculating elements and vectors, through the shared asteroid generator.

- [Size source](https://doi.org/10.1051/0004-6361/201118743)
- [JPL Small-Body Database](https://ssd.jpl.nasa.gov/tools/sbdb_lookup.html): identity, orbit class and brightness.
- [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/): orbit.

No dated test report exists for this body yet.

## Known problems

The body is drawn as a sphere with the shared grid that marks unmapped terrain. Its true shape, pole, colour and albedo pattern are not published, and none is shown. The pole and prime meridian are display conventions.
