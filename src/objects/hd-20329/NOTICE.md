# HD 20329 credits

Radius, mass and temperature: Radius 1.13 +/- 0.02 solar radii from Murgas et al. 2022, the stellar radius of the default parameter set of HD 20329 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2022A&A...668A.158M/abstract); Mass 0.9 +/- 0.05 solar masses from Murgas et al. 2022, the stellar mass of the default parameter set of HD 20329 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2022A&A...668A.158M/abstract); temperature from Murgas et al. 2022, the stellar temperature of the default parameter set of HD 20329 b in the NASA Exoplanet Archive.

Colour: a Planck spectrum at the temperature of Murgas et al. 2022, the stellar temperature of the default parameter set of HD 20329 b in the NASA Exoplanet Archive, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 30398648945512960: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
