# Kepler-1646 credits

Radius, mass and temperature: Radius 0.26 +/- 0.054 solar radii from Morton et al. 2016, the stellar radius of the default parameter set of Kepler-1646 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016ApJ...822...86M/abstract); Mass 0.24 +/- 0.064 solar masses from Morton et al. 2016, the stellar mass of the default parameter set of Kepler-1646 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016ApJ...822...86M/abstract); temperature from Morton et al. 2016, the stellar temperature of the default parameter set of Kepler-1646 b in the NASA Exoplanet Archive.

Colour: a Planck spectrum at the temperature of Morton et al. 2016, the stellar temperature of the default parameter set of Kepler-1646 b in the NASA Exoplanet Archive, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.

Placement: Gaia DR3 source 2102601381497162240: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
