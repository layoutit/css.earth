# Kepler-41 credits

Radius, mass and temperature: Radius 1.29 +/- 0.02 solar radii from Bonomo et al. 2015, the stellar radius of the default parameter set of Kepler-41 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2015A&A...575A..85B/abstract); Mass 1.15 +/- 0.04 solar masses from Bonomo et al. 2015, the stellar mass of the default parameter set of Kepler-41 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2015A&A...575A..85B/abstract); temperature from Bonomo et al. 2015, the stellar temperature of the default parameter set of Kepler-41 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 2080061942886335744, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2080061942886335744: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
