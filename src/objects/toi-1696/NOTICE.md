# TOI-1696 credits

Radius, mass and temperature: Radius 0.2775 +/- 0.008 solar radii from Mori et al. 2022, the stellar radius of the default parameter set of TOI-1696 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2022AJ....163..298M/abstract); Mass 0.255 +/- 0.0066 solar masses from Mori et al. 2022, the stellar mass of the default parameter set of TOI-1696 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2022AJ....163..298M/abstract); temperature from Mori et al. 2022, the stellar temperature of the default parameter set of TOI-1696 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of Mori et al. 2022, the stellar temperature of the default parameter set of TOI-1696 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.

Placement: Gaia DR3 source 270260649602149760: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
