# Kepler-398 credits

Radius, mass and temperature: Radius 0.613 +/- 0.028 solar radii from Rowe et al. 2014, the stellar radius of the default parameter set of Kepler-398 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014ApJ...784...45R/abstract); Mass 0.723 +/- 0.081276 solar masses from TICv8, the stellar mass of Kepler-398 c's parameter set from TICv8 (the default leaves it empty) in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2019AJ....158..138S/abstract); temperature from Rowe et al. 2014, the stellar temperature of the default parameter set of Kepler-398 b in the NASA Exoplanet Archive.
