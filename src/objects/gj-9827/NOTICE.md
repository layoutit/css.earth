# GJ 9827 credits

Radius, mass and temperature: Radius 0.58 +/- 0.03 solar radii from Passegger et al. 2024, the stellar radius of the default parameter set of GJ 9827 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2024A&A...684A..22P/abstract); Mass 0.62 +/- 0.04 solar masses from Passegger et al. 2024, the stellar mass of the default parameter set of GJ 9827 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2024A&A...684A..22P/abstract); temperature from Passegger et al. 2024, the stellar temperature of the default parameter set of GJ 9827 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of Passegger et al. 2024, the stellar temperature of the default parameter set of GJ 9827 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2643842302456085888: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
