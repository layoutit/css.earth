# HD 209458 credits

Shape: a sphere of the radius from G. Torres et al., "Improved parameters for extrasolar transiting planets", ApJ 677, 1324 (2008), arXiv:0801.1841. No image of the photosphere is shown; the neutral gray is a display convention.

Placement: SIMBAD (CDS, Strasbourg) position, proper motion, parallax and radial velocity with the references SIMBAD lists. No measured rotation axis is adopted: the display axis is celestial north.
