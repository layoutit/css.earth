# Pholus

Pholus is a centaur: a small body orbiting the Sun among the giant planets.

## Identity

Pholus is 5145 Pholus, provisional designation 1992 AD. The JPL Small-Body Database classes its orbit as Centaur.

## Sources

Illustrative sphere at the 190 km diameter the JPL Small-Body Database lists for Pholus. No shape model is published. JPL Small-Body Database, physical parameters for 5145 Pholus (1992 AD): diameter 190 km; JPL's stated reference: Earth, Moon, and Planets, v. 89, Issue 1, p. 117-134 (2002).

The orbit comes from JPL Horizons osculating elements and vectors, through the shared asteroid generator.

- [JPL Small-Body Database](https://ssd.jpl.nasa.gov/tools/sbdb_lookup.html): identity, orbit class, brightness and physical parameters with JPL's stated references.
- [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/): orbit.

## Evidence

No dated test report exists for this body yet.

## Known problems

The body is drawn as a sphere with the shared grid that marks unmapped terrain. Its true shape, pole, colour and albedo pattern are not published, and none is shown. The pole and prime meridian are display conventions.
