# Naiad

Measured reference ellipsoid from Karkoschka (2003), DOI10.1016/S0019-1035(03)00002-2. Standard missing-coverage grid; no invented surface imagery. Shared generic object adapter and native CSS triangle renderer.

Voyager survey: NASA/JPL; PDS Ring-Moon Systems Node. Orientation: IAU/WGCCRE; NASA/NAIF.
