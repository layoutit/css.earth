# Kepler-438 credits

Radius, mass and temperature: Radius 0.52 +/- 0.038 solar radii from Torres et al. 2015, the stellar radius of the default parameter set of Kepler-438 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2015ApJ...800...99T/abstract); Mass 0.544 +/- 0.041 solar masses from Torres et al. 2015, the stellar mass of the default parameter set of Kepler-438 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2015ApJ...800...99T/abstract); temperature from Torres et al. 2015, the stellar temperature of the default parameter set of Kepler-438 b in the NASA Exoplanet Archive.

Colour: Gaia DR3 XP spectrum, source 2104675781979819776, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2104675781979819776: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
