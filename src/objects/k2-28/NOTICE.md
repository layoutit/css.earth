# K2-28 credits

Radius, mass and temperature: Radius 0.288 +/- 0.028 solar radii from Hirano et al. 2016, the stellar radius of the default parameter set of K2-28 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016ApJ...820...41H/abstract); Mass 0.257 +/- 0.048 solar masses from Hirano et al. 2016, the stellar mass of the default parameter set of K2-28 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016ApJ...820...41H/abstract); temperature from Hirano et al. 2016, the stellar temperature of the default parameter set of K2-28 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of Hirano et al. 2016, the stellar temperature of the default parameter set of K2-28 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.
