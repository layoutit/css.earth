# WASP-96 credits

Radius, mass and temperature: Radius 1.05 +/- 0.05 solar radii from Hellier et al. 2014, the stellar radius of the default parameter set of WASP-96 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014MNRAS.440.1982H/abstract); Mass 1.06 +/- 0.09 solar masses from Hellier et al. 2014, the stellar mass of the default parameter set of WASP-96 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014MNRAS.440.1982H/abstract); temperature from Hellier et al. 2014, the stellar temperature of the default parameter set of WASP-96 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 4990044668377961984, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 4990044668377961984: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
