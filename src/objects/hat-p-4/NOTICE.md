# HAT-P-4 credits

Radius, mass and temperature: Radius 1.596 +/- 0.06 solar radii from Torres et al. 2008, the stellar radius of the default parameter set of HAT-P-4 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2008ApJ...677.1324T/abstract); Mass 1.248 +/- 0.07 solar masses from Torres et al. 2008, the stellar mass of the default parameter set of HAT-P-4 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2008ApJ...677.1324T/abstract); temperature from Torres et al. 2008, the stellar temperature of the default parameter set of HAT-P-4 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 1291120362349158016, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 1291120362349158016: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
