# Kepler-1650 credits

Radius, mass and temperature: Radius 0.334 +/- 0.039 solar radii from Mann et al. 2017, the stellar radius of the default parameter set of Kepler-1650 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2017AJ....153..267M/abstract); Mass 0.326 +/- 0.047 solar masses from Mann et al. 2017, the stellar mass of the default parameter set of Kepler-1650 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2017AJ....153..267M/abstract); temperature from Mann et al. 2017, the stellar temperature of the default parameter set of Kepler-1650 b in the NASA Exoplanet Archive.

Colour: a Planck spectrum at the temperature of Mann et al. 2017, the stellar temperature of the default parameter set of Kepler-1650 b in the NASA Exoplanet Archive, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.

Placement: Gaia DR3 source 2078524482038704000: position, parallax, proper motion. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
