# KELT-14 credits

Radius, mass and temperature: Radius 1.52 +/- 0.03 solar radii from Turner et al. 2016, the stellar radius of the default parameter set of KELT-14 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016PASP..128f4401T/abstract); Mass 1.239 +/- 0.039 solar masses from Turner et al. 2016, the stellar mass of the default parameter set of KELT-14 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016PASP..128f4401T/abstract); temperature from Turner et al. 2016, the stellar temperature of the default parameter set of KELT-14 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 5560886336446650240, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 5560886336446650240: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
