Chosen by rule: the bare-rock maximum, no light reflected and no heat carried to the night side; the star's temperature is Srivastava et al. 2026, the stellar temperature of the default parameter set of TOI-4552 b in the NASA Exoplanet Archive, a/R* is Srivastava et al. 2026.
