- **Assumptions of the frame.** The axis's position angle and the rotation phase are conventions.

- **Not shown.** TOI-2458 c: found without a transit, and no paper's row measures its whole orbit together (period, eccentricity, periastron time and an inclination with an error bar) (found by radial velocity).
