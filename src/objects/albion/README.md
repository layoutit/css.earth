# Albion

Albion is a trans-Neptunian object in the Kuiper belt.

## Identity

Albion is 15760 Albion, provisional designation 1992 QB1. The JPL Small-Body Database classes its orbit as trans-Neptunian.

## Sources

Pinned inputs are listed in the [source manifest](source/manifest.json).

Illustrative sphere at 130.2 km, estimated from JPL's absolute magnitude H = 7.18 with an assumed albedo of 0.14, the median Vilenius et al. (2014) report for cold classical objects. The size is not measured. The orbit comes from JPL Horizons osculating elements and vectors, through the shared asteroid generator.

## Known problems

The body is drawn as a sphere with the shared grid that marks unmapped terrain. Its true shape, pole, colour and albedo pattern are not published, and none is shown. The pole and prime meridian are display conventions.
