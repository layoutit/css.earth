# WASP-77 A credits

Radius, mass and temperature: Radius 0.91 +/- 0.025 solar radii from Cortés-Zuleta et al. 2020, the stellar radius of the default parameter set of WASP-77 A b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2020A&A...636A..98C/abstract); Mass 0.903 +/- 0.066 solar masses from Cortés-Zuleta et al. 2020, the stellar mass of the default parameter set of WASP-77 A b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2020A&A...636A..98C/abstract); temperature from Cortés-Zuleta et al. 2020, the stellar temperature of the default parameter set of WASP-77 A b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 5178405479961698048, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 5178405479961698048: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
