# Kepler-94 credits

Radius, mass and temperature: Radius 0.76 +/- 0.03 solar radii from Marcy et al. 2014, the stellar radius of the default parameter set of Kepler-94 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014ApJS..210...20M/abstract); Mass 0.81 +/- 0.06 solar masses from Marcy et al. 2014, the stellar mass of the default parameter set of Kepler-94 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014ApJS..210...20M/abstract); temperature from Marcy et al. 2014, the stellar temperature of the default parameter set of Kepler-94 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 2119602202081351168, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2119602202081351168: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
