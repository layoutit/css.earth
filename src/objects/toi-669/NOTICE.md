# TOI-669 credits

Radius, mass and temperature: Radius 0.9882 +/- 0.0176 solar radii from MacDougall et al. 2023, the stellar radius of the default parameter set of TOI-669 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2023AJ....166...33M/abstract); Mass 0.9245 +/- 0.0327 solar masses from MacDougall et al. 2023, the stellar mass of the default parameter set of TOI-669 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2023AJ....166...33M/abstract); temperature from MacDougall et al. 2023, the stellar temperature of the default parameter set of TOI-669 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of MacDougall et al. 2023, the stellar temperature of the default parameter set of TOI-669 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 3777506754255516800: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
