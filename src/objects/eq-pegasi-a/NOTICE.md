# EQ Pegasi A credits

Radius, mass and temperature: Radius 0.35 solar radii from Morin et al., arXiv:0808.1423, Table 1: radius 0.35 solar radii (theoretical radius; R sin i = 0.37(2)) (https://arxiv.org/abs/0808.1423); Mass 0.39 solar masses from Morin et al., arXiv:0808.1423, Table 1: mass 0.39 solar masses (https://arxiv.org/abs/0808.1423); temperature from TESS Input Catalog 8.2 (VizieR IV/39/tic82), TIC 247985094: Teff. Spin: Morin et al., arXiv:0808.1423, Table 1: rotation period 1.06 d and an axis 60 degrees from the line of sight, the values its magnetic maps were made with.

Color: a Planck spectrum at the temperature of TESS Input Catalog 8.2 (VizieR IV/39/tic82), TIC 247985094: Teff, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.

Placement: Gaia DR3 source 2824770686019003904: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
