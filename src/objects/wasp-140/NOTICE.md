# WASP-140 credits

Radius, mass and temperature: Radius 0.87 +/- 0.04 solar radii from Hellier et al. 2017, the stellar radius of WASP-140 b's parameter set from Hellier et al. 2017 (the default leaves it empty) in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2017MNRAS.465.3693H/abstract); Mass 0.9 +/- 0.04 solar masses from Hellier et al. 2017, the stellar mass of WASP-140 b's parameter set from Hellier et al. 2017 (the default leaves it empty) in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2017MNRAS.465.3693H/abstract); temperature from Alexoudi 2022, the stellar temperature of the default parameter set of WASP-140 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 5094154336332482304, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 5094154336332482304: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
