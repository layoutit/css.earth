# Kepler-13 credits

Radius, mass and temperature: Radius 1.74 +/- 0.04 solar radii from Esteves et al. 2015, the stellar radius of the default parameter set of KOI-13 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2015ApJ...804..150E/abstract); Mass 1.72 +/- 0.1 solar masses from Esteves et al. 2015, the stellar mass of the default parameter set of KOI-13 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2015ApJ...804..150E/abstract); temperature from Esteves et al. 2015, the stellar temperature of the default parameter set of KOI-13 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of Esteves et al. 2015, the stellar temperature of the default parameter set of KOI-13 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2130632159136095104: position, parallax, proper motion. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
