# Kepler-1308 credits

Radius, mass and temperature: Radius 0.34 +/- 0.03 solar radii from Morton et al. 2016, the stellar radius of the default parameter set of Kepler-1308 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016ApJ...822...86M/abstract); Mass 0.35 +/- 0.038 solar masses from Morton et al. 2016, the stellar mass of the default parameter set of Kepler-1308 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2016ApJ...822...86M/abstract); temperature from Morton et al. 2016, the stellar temperature of the default parameter set of Kepler-1308 b in the NASA Exoplanet Archive.

Colour: Gaia DR3 XP spectrum, source 2100018422524180864, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.

Placement: Gaia DR3 source 2100018422524180864: position, parallax, proper motion. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
