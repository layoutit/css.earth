# Sources and reuse

Scientific dimensions: Howell et al. (2014), dimensions reported by Schleicher & Knight (2016), https://doi.org/10.3847/0004-6256/152/4/89. The package distributes transcribed numeric parameters and its own smooth approximation, not the paper, radar imagery or an original scientific mesh. Preserve the model assumptions and source attribution. cssEarth code and generated approximation follow the repository MIT license.

JPL Horizons supplies the fixed-epoch orbit records.
