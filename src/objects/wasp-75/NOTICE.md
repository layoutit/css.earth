# WASP-75 credits

Radius, mass and temperature: Radius 1.26 +/- 0.04 solar radii from Gomez et al. 2013, the stellar radius of the default parameter set of WASP-75 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2013A&A...559A..36G/abstract); Mass 1.14 +/- 0.07 solar masses from Gomez et al. 2013, the stellar mass of the default parameter set of WASP-75 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2013A&A...559A..36G/abstract); temperature from Gomez et al. 2013, the stellar temperature of the default parameter set of WASP-75 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 2605161444735454464, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2605161444735454464: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
