# HATS-71 credits

Radius, mass and temperature: Radius 0.4783 +/- 0.006 solar radii from Bakos et al. 2020, the stellar radius of the default parameter set of HATS-71 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2020AJ....159..267B/abstract); Mass 0.4861 +/- 0.006 solar masses from Bakos et al. 2020, the stellar mass of the default parameter set of HATS-71 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2020AJ....159..267B/abstract); temperature from Bakos et al. 2020, the stellar temperature of the default parameter set of HATS-71 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of Bakos et al. 2020, the stellar temperature of the default parameter set of HATS-71 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret (2017), A&A 600, A30, via VizieR J/A+A/600/A30.
