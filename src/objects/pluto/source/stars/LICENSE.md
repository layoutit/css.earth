# HYG Database v4.1

The prepared Pluto starfield derives from HYG Database v4.1 by David Nash / Astronexus, pinned at commit `c7f7f883fe678cc7680169a50ccd7dcc49b060ce`.

Pluto intentionally reuses the same checked registration-field subset as Earth
and Moon (`hyg-v41-field.json`, SHA-256
`49eb1e69ecf508ebebf98e688b5732c96200d9abf3252754a78f2fdd45a1e303`).
This is a shared sky-registration input, not a Pluto observer-epoch simulation.
