# Kepler-378 credits

Radius, mass and temperature: Radius 0.671 +/- 0.035 solar radii from Rowe et al. 2014, the stellar radius of the default parameter set of Kepler-378 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2014ApJ...784...45R/abstract); Mass 0.753 +/- 0.106428 solar masses from TICv8, the stellar mass of Kepler-378 b's parameter set from TICv8 (the default leaves it empty) in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2019AJ....158..138S/abstract); temperature from Rowe et al. 2014, the stellar temperature of the default parameter set of Kepler-378 b in the NASA Exoplanet Archive.

Colour: Gaia DR3 XP spectrum, source 2080095512350543744, through the CIE 1931 2° colour-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 2080095512350543744: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
