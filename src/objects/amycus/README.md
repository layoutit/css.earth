# Amycus

Amycus is a centaur: a small body orbiting the Sun among the giant planets.

## Identity

Amycus is 55576 Amycus, provisional designation 2002 GB10. The JPL Small-Body Database classes its orbit as Centaur.

## Known problems

The body is drawn as a sphere with the shared grid that marks unmapped terrain. Its true shape, pole, colour and albedo pattern are not published, and none is shown. The pole and prime meridian are display conventions.
