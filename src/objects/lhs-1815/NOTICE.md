# LHS 1815 credits

Radius, mass and temperature: Radius 0.501 +/- 0.03 solar radii from Gan et al. 2020, the stellar radius of the default parameter set of LHS 1815 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2020AJ....159..160G/abstract); Mass 0.502 +/- 0.015 solar masses from Gan et al. 2020, the stellar mass of the default parameter set of LHS 1815 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2020AJ....159..160G/abstract); temperature from Gan et al. 2020, the stellar temperature of the default parameter set of LHS 1815 b in the NASA Exoplanet Archive.

Color: Gaia DR3 XP spectrum, source 5500061456275483776, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 5500061456275483776: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
