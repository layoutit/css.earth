# Solar-corona electron density

This package attaches the NASA STEREO-B/SECCHI COR1 Carrington Rotation 2053 P1 μ=10 electron-density reconstruction to the Sun. Their February 2007 measurement frame stays in provenance while the display is explicitly attached to the current Sun scene. The display uses a logarithmic density transfer and explicitly marks its visual bridge across COR1’s unmeasured 1.0–1.5 R☉ blind zone. The float density cube remains unchanged and unfilled.
