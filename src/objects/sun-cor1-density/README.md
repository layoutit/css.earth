# Solar-corona electron density

This package attaches the two NASA STEREO-B/SECCHI COR1 Carrington Rotation 2053 P1 electron-density reconstructions to the Sun as selectable μ=10 and μ=1 lenses. Their February 2007 measurement frame stays in provenance while the display is explicitly attached to the current Sun scene. The radial taper changes encoded display emission only; each float density cube remains unchanged.
