# TOI-1801 credits

Radius, mass and temperature: Radius 0.547 +/- 0.025 solar radii from Mallorquín et al. 2023, the stellar radius of the default parameter set of TOI-1801 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2023A&A...680A..76M/abstract); Mass 0.556 +/- 0.042 solar masses from Mallorquín et al. 2023, the stellar mass of the default parameter set of TOI-1801 b in the NASA Exoplanet Archive (https://ui.adsabs.harvard.edu/abs/2023A&A...680A..76M/abstract); temperature from Mallorquín et al. 2023, the stellar temperature of the default parameter set of TOI-1801 b in the NASA Exoplanet Archive.

Color: a Planck spectrum at the temperature of Mallorquín et al. 2023, the stellar temperature of the default parameter set of TOI-1801 b in the NASA Exoplanet Archive, through the CIE 1931 2° color-matching functions (CIE 2019, CC BY-SA 4.0, doi:10.25039/CIE.DS.xvudnb9b).

Limb darkening: Claret & Bloemen (2011), A&A 529, A75, via VizieR J/A+A/529/A75.

Placement: Gaia DR3 source 3980045523465047168: position, parallax, proper motion and radial velocity. This work has made use of data from the European Space Agency (ESA) mission Gaia, processed by the Gaia Data Processing and Analysis Consortium (DPAC). Identifiers: SIMBAD, CDS, Strasbourg.
