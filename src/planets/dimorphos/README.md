# Dimorphos

DART encounter shape and source-derived radial height, mounted through the generic cssEarth object adapter. Dimorphos is the satellite of Didymos. The source-era surface, post-impact orbital context and illustrative display attitude are distinguished in SOURCE.md and in the view descriptions.

800 retained native PolyCSS raster triangles; prepared lighting defaults on. Use the existing object preparation, source verification and runtime asset setup commands with object id `dimorphos`. No runtime geometry or texture generation is required.
