# OSIRIS observation trial

The candidate manifest preserves the original raw-photograph trial policy.
The application now pins the same GEO image plus its L4 quality companion in
`source/manifest.json`, with a separate illumination-corrected recipe. This
historical manifest is not consumed by the production preparer.

**ESA/Rosetta/MPS for OSIRIS Team MPS/UPD/LAM/IAA/SSO/INTA/UPM/DASP/IDA**.

as stated in [ESA's archive release](https://www.esa.int/Science_Exploration/Space_Science/Rosetta/Rosetta_image_archive_complete).
The original file is preserved byte-for-byte. Image-derived trial assets retain

orientation, measured-camera projection, conservative coverage withholding,
prepared texture packing and browser/difference captures.
