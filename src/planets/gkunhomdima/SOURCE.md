# Gǃkúnǁʼhòmdímà

A distant dwarf-planet candidate with a measured occultation silhouette. This published spheroidal model combines the occultation with its satellite’s orbit; local terrain is unresolved.

Published Maclaurin model with semiaxes 329, 329, 294 km. The satellite orbit is assumed equatorial. The source also permits a slightly triaxial fit; this smooth shape is a constrained model. J2000 pole prior RA 20.6 ± 1.5°, DEC 46.25 ± 0.32° from satellite-orbit alignment. Arbitrary meridian; 11.05 h photometric period has aliases and is not installed as a qualified sidereal spin. The grid marks unmapped terrain.

Source: [Proudfoot et al. (2026), accepted PSJ; occultation and satellite-orbit constraints](https://arxiv.org/abs/2605.28636). Checked 2026-09-09. The source recipe pins units, model assumptions and numerical axes. Shadows and Orbit default off. Rendering uses the generic retained PolyCSS native u raster path. No runtime geometry is generated.
