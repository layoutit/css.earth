Content description for the Small Bodies Radar Shape Models bundle
==================================================================

Note: This bundle was migrated to PDS4 from the PDS3 data set EAR-A-5-DDR-RADARSHAPE-MODELS-V2.0. For PDS3 data sets migrated to PDS4, the following text is taken verbatim from the data set description and confidence level note of the PDS3 data set catalog file. In these cases, some details may not be correct as a description of the PDS4 bundle.

This data set contains radar-based shape models for small solar system bodies, generated by the method developed by Scott Hudson.  (The Peter Thomas shape models, based on optical data, are included in a separate data set,             
urn:nasa:pds:compil.ast-sat.thomas.shape-models).                                         
                                                                              
The current version of this data set contains shape models for the following asteroids:  216 Kleopatra, 1620 Geographos, 2063 Bacchus, 4197 Toutatis (low and high resolution models), 4769 Castalia, 6489 Golevka, 1998 KY26, 52760 (1998 ML14), and 25143 Itokawa.                                                          
                                                                              
Parameters                                                              
==========                                                              
The polyhedral shape models are specified by the coordinates of the vertices of the polyhedron in conjunction with the linkages of the vertices into triangular facets.  These files provide sufficient information for use in visualization applications such as POVray and DXF.  The origin of the models is the center of mass, and the axes are the principal axes.  For all the models except Toutatis, the z-axis is the spin vector or north pole.  For Toutatis, the z-axis is the long axis.  Toutatis is in a long-axis non-principal-axis rotation state.
