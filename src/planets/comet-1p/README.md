# 1P/Halley

One historical shape-model view through the shared object adapter, shell and
retained CSS triangle renderer. The visible panel identifies its large source
uncertainty and illustrative orientation. No photographic texture or regional
confidence map is asserted.

Source identity, frame and limitations are in [SOURCE.md](SOURCE.md); credits
are in [NOTICE.md](NOTICE.md). Preparation uses the shared authored-object recipe:

```sh
node tools/objects/dist/operations.js acquire comet-1p --verify-only
node tools/objects/dist/prepare-authored.js comet-1p --write
pnpm setup:assets --object=comet-1p
```

Qualification is recorded in [HALLEY.md](../../../../docs/comets/HALLEY.md).
