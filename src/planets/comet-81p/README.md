# Wild 2 observed terrain

Source-backed open-surface PoC through the shared object adapter. The 996 retained plates preserve the observed release's boundaries and patches; the unseen side stays absent.

See [SOURCE.md](SOURCE.md) for source, coordinate, coverage and close-view limits, and the shared [qualification record](../../../docs/comets/QUALIFICATION.md) for browser, restoration and performance evidence. This is a reduced model for inspection, not a photographic texture or a claim of current rotational orientation.
