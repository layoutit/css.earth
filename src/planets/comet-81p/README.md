# Wild 2 completed shape model

The NASA PDS full model combines measured Stardust terrain with a fitted ellipsoid on the unseen side. It renders as one closed 992-leaf mesh through the shared object adapter. The shared gray coverage grid marks the estimated ellipsoid and its joining plates; measured terrain keeps the neutral material.

See [SOURCE.md](SOURCE.md) for provenance and interpretation, and the [completion record](../../../docs/comets/WILD2-COMPLETION.md) for current geometry, browser and drag evidence. The display has neutral model coloring and an arbitrary fixed rotational phase.
