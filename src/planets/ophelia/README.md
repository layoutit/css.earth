# Ophelia

Uranus's outer epsilon-ring shepherd, represented by its published prolate
shape and the standard grid. The third axis is assumed equal to the minor axis.
Its mass is inferred from observed ring forcing, not an assumed density.

The single Shape model dataset uses the generic authored terrestrial recipe,
shared adapter and lighting. See [SOURCE.md](SOURCE.md) for the source survey,
physical interpretation and fixed-epoch rotation approximation.

Shared selected acquisition/preparation for `ophelia` reproduces the assets.
The analytic radius table, no-data sentinel and context portrait are versioned
inputs; the font and ESO panorama have pinned download recipes.
