# Varda

Varda is a distant binary-system primary whose outline was measured as it eclipsed a star. Its companion’s orbit helps orient this model, but Varda’s depth remains uncertain.

[Source interpretation](SOURCE.md), [credits](NOTICE.md), and [batch reproduction](../../../docs/distant-worlds/README.md). The Shape model uses the normal unmapped-surface grid. Shadows and Orbit default off.
