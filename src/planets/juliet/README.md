# Juliet

A published prolate shape approximation of Uranus's elongated inner moon.
One Shape model dataset uses the standard gray coverage grid. The source
measures the long and short axes; the third repeats the short axis by assumption.

The package uses the generic authored terrestrial recipe and shared adapter,
including Flood and Shadows. See [SOURCE.md](SOURCE.md) for source qualification,
geometry units and the small fixed-epoch rotation approximation.

Shared selected acquisition/preparation for `juliet` reproduces the assets.
The compact analytic radius table, no-data sentinel and context portrait are
versioned inputs; the font and ESO panorama have pinned download recipes.
