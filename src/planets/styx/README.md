# Styx

A source-informed approximation of Pluto’s innermost small moon. One Shape model
lens preserves the 2025 fitted dimensions and marks unavailable imagery with the
shared cartographic grid. The spin orientation is illustrative and uncertain.

The package uses the existing authored terrestrial recipe and generic object
adapter. Scientific facts, qualification decisions, units and approximation
limits are in [SOURCE.md](SOURCE.md) and `source/measurements.json`.

Run the shared selected acquisition/preparation commands for `styx` to restore
pinned inputs and reproduce its prepared assets. The small analytic radius table,
neutral no-data sentinel and context portrait are versioned source inputs.
